## The colour change

`getChrsColor` in `RunDetail.tsx` must be updated to match, keeping its existing comment:

```ts
case 'Red':    return '#d13b26';   // --ref-red / --bad  "logo red"
case 'Orange': return '#ff6b35';   // --color-orange
case 'Yellow': return '#f3b31f';   // --ref-yellow / --caution  "logo gold"
case 'Green':  return '#2fb457';   // --ref-green, raised for brightness
default:       return '#8b8a84';
```

These are the brand tokens already defined in `index.css`. Three carry a comment naming them as the
logo palette; only green is adjusted, lifted out of the muted `#2f7d3f` in the same hue family.

Worst-pair separation improves on every axis: normal 16.2 → 16.3, **deuteranomaly 1.0 → 11.2**,
protanomaly 4.3 → 11.6. At the shipped values an Orange rating and a Yellow rating are the same
swatch to roughly 6% of men. CHRS orange also pulls clear of verdict orange, ΔE 2.7 → 9.7.

The rating word still renders beside every swatch — brighter colour is not a licence to drop it.
