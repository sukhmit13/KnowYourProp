## COPY LOGIC (build the `.coexplain` sentence in code)
Template (fill from `link` + `subject_address`):
> **Held under the same ownership as the subject.** `{entity}` acquired both this parcel and `{subject_address}` in `{year}`, so the neighbor's chain of title is shown here for a complete ownership picture. *Its recorded prices are this parcel's own — read them as the neighbor's, not the subject's value.*

Rules:
1. **Name the link entity + year.** Pull `entity`/`year` from the shared-ownership record. If `year` is missing, drop "in {year}" (keep the sentence grammatical).
2. **The bold lead + the amber caveat clause are fixed.** The middle clause is the only variable part. Never omit the caveat — it's what stops a reader from treating the neighbor's price as the subject's value.
3. **If the link is by seller/other mechanism**, not a straight purchase, swap the verb: "is the common owner of both this parcel and {subject}" instead of "acquired both … in {year}". Default is the buyer case above.
4. **Multiple co-parcels:** render one `.cop` block per linked parcel; the explanation is per-parcel with its own link entity.

## LOGIC
1. **One `.xfer` per recorded transfer**, newest first. Same card shape as the subject's transfers (serif price, mono date, deed tag + doc, From/To on the right).
2. **Reuse existing transfer flags** if the co-parcel has them (e.g. a "Trust conveyance" / non-arm's-length caution) — apply the same treatment used on the subject's transfers.
3. **No favorability color.** The block is neutral/context; the only accent is the amber caveat clause (`--cautionText`) and the indigo "Co-parcel" chip. No left rail, no red/green.

## CRITICAL DETAILS
1. **Templated, not LLM** — the explanation is code-built from deed fields; zero tokens.
2. **Copy names the shared owner + year, always keeps the amber "neighbor's price, not the subject's value" caveat.**
3. **"Co-parcel" chip** (indigo, link icon) marks it as related; **no blue/indigo left rail** — plain bordered card.
4. **Transfer cards match the subject's** styling and inherit the same non-arm's-length flags.
5. **Serif (`--disp`) ONLY** on the transfer `.price`. Everything else Inter/Mono.
