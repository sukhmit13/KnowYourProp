# Replit Prompt — News & Media Coverage (site-specific, with verification) — build to spec — FINAL

Build the **News & Media Coverage** section: a **Standard Takeaway** box (consistent with every other section, meta content only), then articles grouped by relevance tier (**This parcel → Adjacent/co-parcels**), each card leading with a one-line **Takeaway**, and parcel-direct cards carrying a **Current status** verification line. Content comes from the **News Takeaway generation prompt**. Implement CSS/HTML **verbatim**; check CRITICAL DETAILS.

> **Scope:** site-specific only (articles naming the subject parcel or an immediate co-parcel). **No corridor** here — corridor signals live in the separate Corridor Intelligence section.

## 🔴 Governing rules
1. **Report-data-first** (shared rule): the Current status verification reuses THIS report's own already-displayed data (Business Licenses / current-use, then listing, then permits) — never a fresh external lookup, never a value that could contradict another section. It links to the section it came from.
2. **Consistent Standard Takeaway box** (same component as every section). Its bullets are META — a verdict (does the press name the subject directly?) + the caveat — NOT restatements of the article cards.
3. **Verification is parcel-tier only**, three-state (`consistent` / `appears_superseded` / `no_update`), dated, "appears" not "did", traceable via a link into the source section. `no_update` is the default when report data is silent.
4. **Paraphrase, always linked** — render the generated `takeaway`, never raw article body; `url` required for the Read link; no verbatim quotes.
5. **No sentiment color** — neutral cards; only the caveat bullet + amber age flag carry accent. No green/red.
6. **Fail-closed** — zero matched articles → render nothing (no empty state).

## LOGIC
1. **Tier in code** (parcel vs adjacent). Groups render parcel → adjacent; within a group, date desc. No corridor.
2. **Age flag in code** (`as_of − date > ~12 mo`).
3. **Verification is report-data-first** — the generator built `verification` from the report's own Business Licenses / listing / permits (priority order), defaulting to `no_update` when silent. The renderer only binds it and links to `source_anchor`; it does not compute status or fetch anything.
4. **Render only what exists** — omit an empty tier entirely; omit `.artverify` when `verification` is null.
5. **Fail-closed** — `section == null` → render nothing.
