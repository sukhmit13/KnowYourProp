Implement CSS/HTML **verbatim**; check every CRITICAL DETAIL.

## LOGIC
1. **Sort = each firm's most-recent permit year on this property, DESCENDING.** Tie-break by permit count (then declared value) descending — that's why a firm with 2 permits in 2019 outranks one with 1 permit in 2019. (Do NOT sort by value alone or by role.)
2. **No scope text.** Never render the permit description / work-scope string in this card. The row is: role, name, "Here" record, citywide line (or no-match). That's it.
3. **One row per firm**, deduped by license number (fallback normalized name) across all the building's permits — aggregate permit count, summed declared value, most-recent year. (Same dedup as the rest of the professionals logic — this card just renders the result.)
4. **Role label + icon** come from the permit's contractor-type field via the lookup above; unknown role → the wrench fallback icon + the raw role text as the label.
5. **Era chip** = era of the firm's most-recent permit here (current vs prior owner, from the last-sale-date split). Neutral/categorical — indigo `cur`, grey `prior`, never favorability.
6. **Citywide line** is conditional on a confident license-number match (unchanged from existing logic): matched → the `.pcite` stats + View profile; not matched → the `.pcite.nomatch` line. Firms always render their "Here" line regardless.

## CRITICAL DETAILS (check ALL)
1. **All icons and role labels are indigo** — one indigo badge style for every role (`.pic` = `--indigoSoft` bg, `--indigo` stroke; `.prole` = `--indigo`). No design-vs-trade color split, no grey pills.
2. **Role icon varies by trade** via the lookup (compass/hard-hat/bolt/brick/sign/clipboard/…), wrench fallback for unmapped roles — so every row has a clean indigo badge and the list is scannable by trade.
3. **Firm NAME is the largest element** in the row (15px, weight 600). Role is a small indigo mono eyebrow above it; the "Here" stat is quiet mono below.
4. **No permit work-scope text anywhere** in this card.
5. **Sorted most-recent-work-first**, tie-break by permit count desc; header carries the "Most recent work first" note.
6. **`.pcite.nomatch`** for unmatched firms (muted, no dashed top border); matched firms get the full citywide line + "View profile →".
7. **Era chips neutral** (indigo current / grey prior), never red/green.
8. Rows separated by a 1px top border (`.pro2` + `:first-of-type` removes it on the first); footer note is the fixed `.profind` copy.
