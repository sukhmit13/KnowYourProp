## CRITICAL DETAILS — the spots that usually get missed (get ALL of these right)
1. **The Orange Tag badge is SOLID `--chrsOrange` with white text** — not an outline, not marigold, not indigo. Landmark icon is white, sits left of the text.
2. **The section header uses the filled indigo SQUARE** (top-level marker), not an icon. Only the badge on the right is orange.
3. **The resource-card icon chip uses `--chrsOrangeSoft` background with a `--chrsOrange` stroke icon** — a soft peach square, orange icon. Do not make it indigo.
4. **The CHRS Rating value has a 9×9 orange square swatch** inline before the word "Orange".
5. **Takeaway bullet dots are colored per bullet:** bullet 1 = caution (amber) `.cn.c`, bullet 2 = green `.cn.g`, bullet 3 = neutral grey `.cn.n`. This two-sided coloring is the point — do not make them all one color.
6. **"What This Means" bullet dots** likewise: the two constraint bullets = `.con` (amber), the tax-incentive bullet = `.up` (green), the last = `.neu` (grey).
7. **Numbers/keywords are bolded to `--ink`** inside otherwise `--ink2` bullet text (e.g. **demolition**, **Class L**, **(20%)**, **(25%)**).
8. **The `.rgrid` is exactly two columns** (`1fr 1fr`) with `13px 22px` gap — Address top-left, Parcels top-right, CHRS Rating bottom-left, Era bottom-right.
9. **Source row**: indigo external-link icon + "Historic Preservation Division" (link) · muted "Source:" text, separated by a light `·`. Top border above it.
10. **Fonts:** the takeaway headline and nothing else here uses Instrument Serif (`--disp`); labels are JetBrains Mono; body is Inter. Don't render the headline in Inter.

## Content accuracy note (not styling — verify before shipping)
An "Orange" rating in the Chicago Historic Resources **Survey** primarily triggers the **demolition-delay ordinance** (a ~90-day hold), which is NOT the same as being an officially **designated** Chicago Landmark (which carries the strict alteration controls). The current "What This Means" restrictions bullets read firmly — confirm which protections actually apply to a survey-Orange parcel vs. a designated landmark, and soften if needed. The takeaway's third bullet already hedges this.
