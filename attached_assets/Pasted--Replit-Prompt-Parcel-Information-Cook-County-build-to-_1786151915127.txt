## LOGIC (two small derived pieces — the rest is pure display of existing data)

   - If `apartments == bedrooms == bathrooms` → state "{N} 1-bedroom units" / "…configured as {N} matching 1BR/1BA apartments." (This is the six-flat case shown.)

2. **Listing-discrepancy caveat (conditional).** Render the `.caveat` block ONLY when: (a) an active listing exists for this property, AND (b) its unit/config info conflicts with the county record. Fill `{LISTING_DESC}` and `{COUNTY_DESC}` from the two sources. If there is no active listing, or the listing agrees with the county, DO NOT render the caveat at all. Keep the wording's lean ("the listing is likely the more accurate picture — verify") — the listing reflects current state, the county record can be stale, but it still says "verify."
