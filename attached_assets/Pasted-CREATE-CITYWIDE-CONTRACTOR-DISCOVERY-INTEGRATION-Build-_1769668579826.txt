- Use this as fallback if no specific specialty matches

CLASSIFICATION FUNCTION:
───────────────────────

Create function: classifyPermitSpecialty(permit)

Input: permit object with work_description and permit_type fields
Output: { primary: 'kitchen', all: ['kitchen', 'flooring'], score: 1 }

Logic:
1. Convert work_description to lowercase
2. Check for "new construction" first (check permit_type and description)
3. Check for "gut rehab" second (distinct category)
4. Check each specialty's keywords in order
5. Track all matching specialties
6. Return primary (first match) and all matches
7. If no matches, return 'general'

Score calculation:
- score = 1 if only one specialty matches (highly specialized permit)
- score = 0.5 if 2-3 specialties match (multi-specialty permit)
- score = 0.3 if 4+ specialties match (general renovation)

PART 2: BUILD CONTRACTOR DATABASE FROM PERMITS
═══════════════════════════════════════════════════════════════════════════

CREATE: /server/services/contractorAggregation.js

This service processes all building permits and creates contractor rankings.

PROCESS:
───────

1. Query ALL building permits from Chicago Data Portal (last 5 years)
   URL: https://data.cityofchicago.org/resource/ydr8-5enu.json
   
   Note: API limits to 50,000 records per query
   Use pagination: ?$limit=50000&$offset=0
   Continue with $offset=50000, $offset=100000, etc. until no more results

2. For each permit, extract:
   - contractor_1_name (normalize: trim, uppercase, remove extra spaces)
   - contractor_1_company_name
   - work_description
   - permit_type
   - estimated_cost (convert to number)
   - issue_date
   - address fields (street_number, street_direction, street_name, suffix)
   - community_area (for neighborhood mapping)
   - ward

3. Classify each permit's specialty using classifyPermitSpecialty()

4. Group permits by contractor (use normalized contractor_1_name)

5. For each contractor, calculate:
   
   BASIC METRICS:
   - totalPermits: Total count of permits
   - yearsActive: First permit date to last permit date
   - lastPermitDate: Most recent permit
   - firstPermitDate: Oldest permit in dataset
   
   SPECIALTY ANALYSIS:
   - Count permits by specialty (primary specialty only)
   - primarySpecialty: Specialty with highest count
   - specializationScore: (primarySpecialtyCount / totalPermits) * 100
   - secondarySpecialties: Other specialties with 10+ permits
   
   GEOGRAPHIC ANALYSIS:
   - Count permits by community_area
   - topNeighborhoods: Top 3 community areas by permit count
   - Map community_area numbers to neighborhood names using Chicago's 
     community area reference
   
   FINANCIAL METRICS:
   - totalReportedValue: Sum of all estimated_cost values
   - avgProjectValue: Mean of estimated_cost (exclude $0 values)
   - Remove outliers (top/bottom 5%) before calculating average
   
   ACTIVITY METRICS:
   - permitsByYear: Count of permits per year (2021, 2022, 2023, 2024, 2025)
   - recentActivity: Count of permits in last 90 days
   - isActive: true if last permit within 30 days
   
   PROJECT LIST:
   - recentProjects: Array of last 20 permits with:
     * address (formatted: "1234 N Main St")
     * date (issue_date)
     * specialty (primary)
     * description (work_description, truncated to 100 chars)
     * reportedValue (estimated_cost)

6. Save aggregated data to: /server/data/contractors/rankings.json
