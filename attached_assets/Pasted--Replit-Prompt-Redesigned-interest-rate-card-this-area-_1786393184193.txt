# Replit Prompt — Redesigned interest-rate card (this-area vs. today, with conditional caution) — build to spec

Replace the current avg-interest-rate display in the **Local Mortgage Market Activity (HMDA)** section with a redesigned **side-by-side comparison card**: the area's closed-loan average on the left, today's market benchmark on the right, and a center delta that shows the gap and direction. The delta is **neutral by default** and turns **marigold caution** only when today is *materially* higher. Implement CSS/HTML **verbatim**; check CRITICAL DETAILS.

## 🔴 Today's rate is DATA, reused — never LLM-generated, never a second fetch
The right-hand "today" value is the **same** rate you already fetch for the valuation calculator. Do **NOT** add a second fetch and do **NOT** let the model state a rate from its own knowledge. Read the shared value and map it into the three fields below (same contract as the HMDA takeaway):
- `market_rate_today` ← the calculator's current rate (normalize to a percent number, 2 dp for display; keep full precision for the math)
- `market_rate_asof` ← the date that rate was valid for
- `market_rate_source` ← the label (e.g. "Freddie Mac PMMS 30-yr")

If `market_rate_asof` is older than ~2 weeks (stale), **fail closed**: hide the "today" side / the whole comparison rather than showing a stale number as "today."

## LOGIC (all computed in code — never by the model)
Compute `diff = market_rate_today − area_avg_rate` (in percentage points) and render:

1. **Direction** (arrow + word), from the sign of `diff`:
   - `diff > 0` → `HIGHER_OR_LOWER = "higher"`, right-pointing arrow `ARROW_PATH = <path d="M5 12h14"/><path d="m13 6 6 6-6 6"/>`
   - `diff < 0` → `HIGHER_OR_LOWER = "lower"`, left-pointing arrow `ARROW_PATH = <path d="M19 12H5"/><path d="m11 18-6-6 6-6"/>`
   - `|diff| < 0.05` (≈ in line) → still show the number; either arrow is fine, keep it neutral.
2. **Signed magnitude:** `SIGNED_DELTA = (diff >= 0 ? "+" : "−") + abs(diff).toFixed(2)` → e.g. `+0.20`, `−0.15`, `+1.20`.
3. **Caution class — the only place color appears:**
   - `CAUTION_CLASS = " caution"` **only when `diff >= 1.00`** (today materially higher — a full point-plus above area closings).
   - Otherwise `CAUTION_CLASS = ""` (neutral). **Down-case is ALWAYS neutral — never green, never colored**, even for a large negative `diff`. The asymmetry is intentional: a big upward move is a real "financing got pricier" watch-out; a downward move is not a favorability signal for a neutral tool.
   - Threshold lives in code as a single constant (`MATERIAL_GAP_PT = 1.00`). It is a tunable judgment call — `0.75` is defensible if you want the caution to appear a bit more often; do not go below `0.75` or normal rate noise starts coloring.
4. **`EXPLAIN` sentence** is directional prose, hedged — the area figure is a full-year blended average (conventional/FHA/VA), today's is a current 30-yr snapshot, so they are **not apples-to-apples**. Say "a touch more / a bit more," never "exactly X bps." Two variants:
   - Normal gap: *"<b>Loans here closed just {below/above} today's market.</b> The {year} tract average (a full-year blend of conventional, FHA and VA first-lien loans) is about {|diff| in bps} under/over the current 30-year benchmark — so a buyer financing now would likely pay a {touch more / bit less} than recent closings here."*
   - Material upward gap (caution): *"<b>Financing has gotten meaningfully pricier.</b> Today's benchmark sits a full point-plus above what loans here closed at in {year} — a real 'rates have moved' signal worth flagging."*

## CRITICAL DETAILS
1. **Reused rate, no second fetch** — `market_rate_today` is the SAME value the valuation calculator already pulls; import from the single source. `as_of` travels with it; stale (> ~2 weeks) → fail closed (hide the today side / comparison).
2. **Model never states a rate** — the number is a bound data field; direction, sign, and the caution class are all computed in code.
3. **Caution is up-only and rare** — marigold appears ONLY when `diff >= 1.00`. Never red, never green, and the down-case stays neutral. One constant `MATERIAL_GAP_PT` controls it.
4. **Caution styling is the solid-marigold circle** (`background:var(--caution)`, white arrow) + amber text `#b26c07` (NOT pure `--caution` on text — too low-contrast at 13px, NOT `--cautionText` brown either). Only the `.rcdelta.caution` block changes; the neutral block is untouched.
5. **Comparison is directional + hedged** — full-year blended avg vs. today's snapshot, not a precise spread. Never claim an exact bps difference in the prose.
6. **Serif (`--disp`) only** on the two big rate numbers (`.rcside .val`). Labels, delta, subs, and fine print are Mono; the explain sentence is Inter. No other element uses the serif.
7. **Grid is `1fr auto 1fr`** — the delta column sizes to content and stays centered; the two rate sides balance. `.rcside.today` is right-aligned.
