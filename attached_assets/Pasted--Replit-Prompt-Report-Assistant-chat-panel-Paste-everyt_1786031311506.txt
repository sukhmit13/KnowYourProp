# PART B — Assistant behavior contract (NOT optional styling)

The provenance UI in Part A is only trustworthy if the assistant's logic actually enforces these rules. The block color must reflect the *true* origin of each sentence — decorating outside info with a "From this report" tag would be worse than no tags at all.

1. **Report/backend first.** For every question, the assistant must first attempt to answer from this property's report data and the site's backend for this property. Only when the report/backend genuinely cannot answer may it use outside/general knowledge. This is a retrieval-order rule, not a label.

2. **Segment by true source.** Structure each answer as blocks. Any statement grounded in this property's report/backend data → a `report` block, cited to the specific field/section it came from. Any statement from general knowledge or an external source → an `outside` block. If a single answer mixes both (like the TIF example: the property-specific fact is from the report, the explanation of what TIF *means* is general), split it into a report block AND an outside block. Never label outside content as "from this report."

3. **Citations are mandatory for outside blocks, and must be real.** Every `outside` block must carry a verifiable citation with a working URL to the actual source — not a plausible-sounding source name with no link. If the assistant cannot produce a real citation for a claim, it should not present that claim as sourced; say it's general knowledge or decline.

4. **Never fabricate a report field.** A `report` block may only cite a field/section that actually exists in this report. If the report doesn't contain the answer, do not invent a report citation — move the content to an outside block or state that the report doesn't cover it.

5. **Scope honesty.** Keep the existing "I only have access to the data shown in this report" framing. When the report lacks something, say so plainly rather than guessing and tagging it as report data.

## Acceptance check
Ask "Is this property in a TIF district, and what does that mean?" → the answer should show a **report block** ("not in a TIF district," cited to the report's TIF field) followed by an **outside block** (what TIF means, cited to a real City of Chicago URL). Ask something the report fully answers (e.g. "What's the max FAR here?") → a single report block, no outside block, no external citation.
