## LOGIC (derived — compute in the backend, do not hardcode)
1. **Released-doc matching.** Match each mortgage to its release/satisfaction. A mortgage with a recorded release is discharged → mark its table row `released` (strike-through + "✓ Released") and EXCLUDE it from active-debt math.
2. **Lien Position `{POSITION}`.** Among **unreleased** mortgages, order by record date. Earliest unreleased = 1st, next = 2nd, etc. If exactly one unreleased mortgage → `"1st · sole active"`. If several → show this one's ordinal + count (e.g. `"2nd of 2"`). **If it can't be determined, render `"Undetermined"` — never default to "1st".**
3. **Active vs total.** `{N_MTG}` in the KPI is the lifetime count; the takeaway's leverage claim must use **total active (unreleased) secured debt**, i.e. the SUM of unreleased mortgage amounts — not just the one shown. If more than one active mortgage exists, the takeaway must NOT say "single mortgage."
4. **Leverage / "~a quarter".** LTV = total active recorded debt ÷ estimated market value (from the parcel/assessment data). This is an estimate off original recorded amounts — hedge the wording ("roughly," "estimated"). If estimated value isn't available, drop the fraction and just state the amount.
5. **Refinancing runway.** `{ELAPSED_PCT}` = (today − recorded) ÷ term × 100; `{ELAPSED_YRS}`, `{YRS_LEFT}` from the 30-yr term. Refi-risk tier is your existing rule (Low when many years remain).
6. **Title status badge `{TITLE_STATUS}`.** Green "Clear title" only when active liens = 0 AND lis pendens = 0 AND no foreclosure. Otherwise reflect the real state (e.g. amber "Liens on file" / red "Lis pendens") — do not hardcode "Clear title."
7. The **verify caveat always shows** in Debt Snapshot (recorded amount vs current balance is always a real limitation).
