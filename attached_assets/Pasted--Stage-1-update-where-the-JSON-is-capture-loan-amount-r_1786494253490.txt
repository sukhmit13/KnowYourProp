## 2. Your two findings — now in the extraction
You were right on both, and both are real accuracy bugs, not edge cases:

**(a) Loan amount ≠ Consideration Amount.** The index "Consideration Amount" ($798,000) is a transfer-tax/valuation figure, not the debt. The mortgage doc `1618022008` states a **$399,000** loan in its body. Pulling the index number would overstate leverage by ~2×. The prompt now reads `amount` from the **document body** and parks any consideration figure in a separate `index_consideration_amount` so a mismatch is visible instead of silently wrong.

**(b) The modification supersedes the original terms.** Doc `2121004479` (2021) clarifies the loan amount and adjusts maturity + interest rate. The prompt now captures a `modifies` object on modification docs, and the lender comes through on both docs.

## 3. Schema additions (swap the EXTRACTION_PROMPT — nothing else changes)
New fields: `execution_date`, `index_consideration_amount`, `interest_rate`, and a `modifies` object.

```json
{
  "doc_number": string,
  "doc_type": "mortgage|release|satisfaction|assignment|modification|subordination|deed|lis_pendens|foreclosure|notice_default|judgment_lien|tax_lien|mechanics_lien|ucc|other",
  "recording_date": "YYYY-MM-DD|null",
  "execution_date": "YYYY-MM-DD|null",
  "pins": [string],
  "parties": { "borrower": string|null, "lender": string|null, "assignor": string|null, "assignee": string|null },
  "amount": number|null,                       // LOAN principal from the doc BODY — NOT the index consideration
  "index_consideration_amount": number|null,   // consideration/transfer figure if the doc restates it (mismatch flag)
  "interest_rate": number|null,                // annual %, e.g. 5.25
  "maturity_date": "YYYY-MM-DD|null",
  "modifies": {                                // null unless doc_type = modification/amendment
    "references_doc": string|null,
    "new_amount": number|null,
    "new_maturity_date": "YYYY-MM-DD|null",
    "new_interest_rate": number|null,
    "summary": string|null
  },
  "references_docs": [string],
  "debtor_name": string|null,
  "is_partial": boolean,
  "is_blanket": boolean,
  "extraction_confidence": "high|medium|low"
}
```

Paste-ready `EXTRACTION_PROMPT` is already updated in **replit-agent-stage1.md** and **stage1-ingest-extract.md** — copy that string into the Agent. Only the prompt string changes; `getDocText`, `extractDoc`, caching, and concurrency stay exactly as built.
