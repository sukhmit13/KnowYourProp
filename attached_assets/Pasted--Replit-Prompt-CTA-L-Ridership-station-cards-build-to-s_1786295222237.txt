## HTML (verbatim; loop per station)
```html
<div class="station">
  <div class="sthead">

    <div class="track"><span class="tick" style="left:{MEDIAN_PCT}%"></span><span class="tick" style="left:{SYSAVG_PCT}%"></span><span class="mark" style="left:{STATION_PCT}%"></span></div>
    <div class="scale"><span>0</span><span>{MAX}</span></div>
    <div class="cmpfoot">This station <b>{WEEKDAY_INT}</b> · Median {MEDIAN} · System avg {SYSAVG} · busier than <b>{PERCENTILE}%</b> of stations</div>
  </div>
</div>
```

## LOGIC
1. **Line badges are DATA-DRIVEN, one per line the station serves.** Loop the station's `lines[]` and render a `.lineb` per line in CTA order, each with the matching color class. Belmont-O'Hare / Logan Square are Blue-only here, but interchange stations (e.g. a Red+Brown+Purple stop) must show all their badges. **Reuse the exact `.lineb` component the CTA Rail Stations list already uses — do not fork a second badge.**
2. `.track` marks (percent positions on the 0→`{MAX}` scale): `MEDIAN_PCT = median/MAX*100`, `SYSAVG_PCT = sysavg/MAX*100`, `STATION_PCT = station_weekday/MAX*100`. `MAX` = the busiest L station's weekday avg (system max). Two grey ticks (median, system avg), one ink marker (this station).
3. `{PERCENTILE}` = this station's rank as "busier than X% of stations" = `(1 - rank/total)*100`, rounded.
4. `{ACTIVITY_LABEL}` from the percentile tier (e.g. ≥75th "Strong station activity"). Keep it green when high; a low-activity station would use a neutral label — don't force green.

## CRITICAL DETAILS
1. **Line badge added next to the station name**, using the **same component + color tokens** as the CTA Rail Stations list (single source of truth for line colors). One badge per line served; loop `lines[]`.
2. **Yellow Line badge uses dark text** (`.lineb.yellow{color:var(--ink)}`) — yellow-on-white with white text is unreadable; every other line is white text.
3. **Station name = 18px** (`.stname`), matching the Metra section's station-name size. Ideally share ONE class/token with the Metra station names so they can't drift apart.
4. **KPI value numbers = 27px** (`.kpi .v`), down from the oversized ~34px. Instrument Serif.
5. **Serif (`--disp`) only** on the KPI numbers. Station name, chips, labels, footnote are Inter/Mono.
6. Comparison-bar fills/marks are positioned by percent; the marker is a solid ink bar, ticks are grey.
