# Replit Prompt — Transit Access & Ridership takeaway — build to spec

Fix the **Transit Access & Ridership** takeaway. The bug: on a bullet whose text wraps to two lines, the "Closest Stops" chip stretches to the full row height, so it's taller than the others. Fix = the chip keeps ONE fixed size and centers vertically. Also: the headline is the **standard 21px** takeaway size (not 24px). Implement CSS/HTML **verbatim**; check the CRITICAL DETAILS.

## The core fix (this is the whole ask)
The bullet row is a flex row; by default `align-items:stretch` makes the chip grow to the row height. Two rules fix it:
```css
.cn  { display:flex; align-items:flex-start; gap:12px; }  /* dot + text stay top-aligned to line 1 */
.jbtn{ flex:none; align-self:center; }                    /* chip keeps its own size, centers vertically */
```
`flex:none` stops the chip growing/shrinking; `align-self:center` overrides the row's alignment for just the chip so it sits centered against a 1- or 2-line bullet. Dot and text keep `flex-start` so they align to the first line.
