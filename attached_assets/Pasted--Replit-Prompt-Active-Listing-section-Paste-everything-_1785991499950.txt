## What's wrong with the current version (the goals of this redesign)
1. **Neutral facts are styled as warnings.** The current "Disclosed in Listing" box uses a yellow/amber background with ⚠️ warning triangles on things like "Residential units are rented" — which is a neutral (often positive) fact, not a risk. Stop editorializing neutral facts as alarms.
2. **The "unverified" caution color is used in two places, diluting it.** Consolidate the amber/caution signal into ONE banner at the top. Everything below it should be neutral.
3. **Facts are duplicated** (list price and the theater/apartments appear in both prose and bullets). Each fact should appear once.
4. **The "compare with official records" line is passive.** Make it an actionable call-to-action.

## Consistency rules
- **Only one amber accent** in the whole section — the top unverified banner. Nothing else is amber/yellow.
- Every other accent is indigo, green (status only), or neutral grey.
- Stat-tile numbers use Instrument Serif (`--disp`) at ~28px, normal weight — not bold sans.
- Each fact appears once: tiles for the metrics, prose for the narrative, grouped bullets for the highlights. No repeats across them.
