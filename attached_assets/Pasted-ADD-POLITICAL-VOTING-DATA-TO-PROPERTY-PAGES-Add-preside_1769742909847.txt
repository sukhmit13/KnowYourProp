ADD POLITICAL VOTING DATA TO PROPERTY PAGES

Add presidential election results, mayoral election results, and 
referendum results to property analysis pages. Display by community 
area (to match existing demographic data).

═══════════════════════════════════════════════════════════════════════════
PART 1: DOWNLOAD ELECTION DATA
═══════════════════════════════════════════════════════════════════════════

Manually download these datasets from Chicago Data Portal or Chicago 
Board of Elections:

SEARCH CHICAGO DATA PORTAL:
https://data.cityofchicago.org/browse?q=election

Look for datasets:
1. Presidential Election Results 2024 (by ward or precinct)
2. Presidential Election Results 2020 (by ward or precinct)
3. Presidential Election Results 2016 (by ward or precinct)
4. Mayoral Election Results 2023 (by ward or precinct)
5. Mayoral Election Results 2019 (by ward or precinct)
6. Recent Referendum Results (by ward or precinct)

If available by precinct with community area, use that.
If only available by ward, we'll map wards to community areas.

Download and save to: /server/data/elections/raw/

═══════════════════════════════════════════════════════════════════════════
PART 4: CALCULATE CLASSIFICATION & INDICATORS
═══════════════════════════════════════════════════════════════════════════

When processing the data, calculate:

1. Average Democratic margin across 3 presidential elections
2. Classify based on average margin:
   - D+40 or more: "Strongly Democratic", 🔵🔵🔵🔵🔵
   - D+15 to D+39: "Moderately Democratic", 🔵🔵🔵
   - D+14 to R+14: "Swing Area", 🟣
   - R+15 to R+39: "Moderately Republican", 🔴🔴🔴
   - R+40 or more: "Strongly Republican", 🔴🔴🔴🔴🔴

3. Determine trend:
   - Compare 2024 margin to 2016 margin
   - If difference < 3 points: "Stable"
   - If margin increased (more D): "Trending more Democratic"
   - If margin decreased (more R): "Trending more Republican"

IMPLEMENTATION NOTES
═══════════════════════════════════════════════════════════════════════════

DATA SOURCES (in order of preference):
1. Chicago Data Portal - search for election results datasets
2. Chicago Board of Elections website - download results
3. Cook County Clerk - for county-wide results

FILE STRUCTURE:
- Store raw downloads in: /server/data/elections/raw/
- Store processed JSON in: /server/data/elections/community_area_elections.json
- Single file with all election data (presidential, mayoral, referendums)

UPDATE FREQUENCY:
- Presidential: Every 4 years (next: 2028)
- Mayoral: Every 4 years (next: 2027)
- Referendums: As they occur (check after each major election)

PERFORMANCE:
- JSON file will be ~100-200 KB (all 77 community areas)
- Load once at server startup
- Lookups are instant (simple object access)
- No API calls needed

ERROR HANDLING:
- If community area not found in election data, show:
  "Political data not available for this area"
- Don't break the page, just hide the section

STYLING:
- Collapsible by default (keeps page clean)
- "Show Political Profile ▼" button to expand
- Color code: Blue for Democratic, Red for Republican, Purple for swing
- Keep formatting consistent with rest of site
