## 1. The Simple / Detailed toggle is the wrong primitive

This is almost certainly why the section does not look like the targets.

Four sites build the switch out of `.kyp-block`:

```
ValuationCalculator.tsx:399, 400   business Simple / Detailed
ValuationCalculator.tsx:494        tier Simple
ValuationCalculator.tsx:537, 538   tier Simple / Detailed
```

```tsx
<button type="button" className={`kyp-block ${tier === "simple" ? "ind" : "wash"}`} …>Simple</button>
```

`.kyp-block` is the **headline-statistic** primitive — a filled card sized for a 36px display
numeral. Using it for a two-state switch produces two large colored slabs where the targets have a
compact segmented control, and it is the single biggest visual difference from the mockups.

`grep -c 'kyp-seg' ValuationCalculator.tsx` → **0**, while `DevelopmentSection.tsx` and
`ProjectUseAnalysisSpine.tsx` both already use it. Use the same primitive here:

```tsx
<div className="kyp-segrow">
  <div className="kyp-seg">
    <button type="button" className={tier === "simple" ? "on" : ""}
      aria-pressed={tier === "simple"} onClick={() => setTier("simple")}>Simple</button>
    <button type="button" className={tier === "advanced" ? "on" : ""}
      aria-pressed={tier === "advanced"} onClick={() => setTier("advanced")}>Detailed</button>
  </div>
  <div className="spacer" />
  <div className="kyp-scopenote">{/* the one-line note opposite the control */}</div>
</div>
```

Apply at all four sites. Keep `aria-pressed`. Reference: `val-dc-target.html`,
`val-mf-target.html`.

| header `Coverage check` / value `1.14×` | header `Your NOI` / value `$103,596` / `per year` | the header states the quantity being tested. DSCR is already a block in Deal at a Glance and a lit band immediately below |

| row `Common commercial floor` — sub `NOI required for 1.25× coverage` | `Lender minimum` — sub `1.25× — the floor most commercial lenders underwrite to` | names whose rule it is |

| pill `Gap $-49,737` | pill `−$49,737` | "Gap" plus a signed number reads twice, and the pill color already says which side |
