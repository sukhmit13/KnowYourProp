# REPLIT AI AGENT - ADD SBA & CDFI LOAN DATA

---

## GOAL

Add SBA loan data to property reports, similar to HMDA residential mortgage data.

**What you're adding:**
- SBA 7(a) loans (small business/commercial)
- SBA 504 loans (commercial real estate)
- CDFI directory (community lenders in area)

**Like HMDA but for:** Commercial properties, small businesses, commercial real estate

---

## DATA SOURCES (ALL FREE & PUBLIC)

### **1. SBA 7(a) Loans** ✅

**What:** Small business loans (can include commercial RE)

**URL:** https://data.sba.gov/dataset/7-a-504-foia

**Download:**
- FY2020-Present: https://data.sba.gov/dataset/0ff8e8e9-b967-4f4e-987c-6ac78c575087/resource/d67d3ccb-2002-4134-a288-481b51cd3479/download/foia-7a-fy2020-present-asof-250930.csv
- FY2010-2019: https://data.sba.gov/dataset/0ff8e8e9-b967-4f4e-987c-6ac78c575087/resource/3f838176-6060-44db-9c91-b4acafbcb28c/download/foia-7a-fy2010-fy2019-asof-250930.csv

**Updated:** Quarterly

**Fields:**
- BorrowerName
- BorrowerStreet
- BorrowerCity
- BorrowerState
- BorrowerZip
- GrossApproval (loan amount)
- ApprovalDate
- NAICS Code (business type)
- JobsSupported
- BankName (lender)

### **2. SBA 504 Loans** ✅

**What:** Commercial real estate loans (THIS IS THE GOOD ONE!)

**URL:** https://data.sba.gov/dataset/7-a-504-foia

**Download:**
- FY2010-Present: https://data.sba.gov/dataset/0ff8e8e9-b967-4f4e-987c-6ac78c575087/resource/4ad7f0f1-9da6-4d90-8bdb-89a6f821a1a9/download/foia-504-fy2010-present-asof-250930.csv

**This is perfect for commercial property reports!**

## FILE 1: `sba_data_loader.py`

**Download and load SBA data (run quarterly)**

```python
"""
Download and process SBA loan data
Similar to HMDA data loader
"""

import requests
import pandas as pd
import sqlite3
from datetime import datetime


class SBADataLoader:
    """
    Download and load SBA 7(a) and 504 loan data
    """
    
    def __init__(self, db_path='sba_loans.db'):
        self.db_path = db_path
        
        # Download URLs
        self.urls = {
            '7a_recent': 'https://data.sba.gov/dataset/0ff8e8e9-b967-4f4e-987c-6ac78c575087/resource/d67d3ccb-2002-4134-a288-481b51cd3479/download/foia-7a-fy2020-present-asof-250930.csv',
            '7a_2010_2019': 'https://data.sba.gov/dataset/0ff8e8e9-b967-4f4e-987c-6ac78c575087/resource/3f838176-6060-44db-9c91-b4acafbcb28c/download/foia-7a-fy2010-fy2019-asof-250930.csv',
            '504_recent': 'https://data.sba.gov/dataset/0ff8e8e9-b967-4f4e-987c-6ac78c575087/resource/4ad7f0f1-9da6-4d90-8bdb-89a6f821a1a9/download/foia-504-fy2010-present-asof-250930.csv'
        }
    
    def download_and_load_all(self):
        """
        Download all SBA data and load into database
        Run this quarterly when SBA updates data
        """
        print("="*60)
        print("DOWNLOADING SBA LOAN DATA")
        print("="*60)
        
        # Download and load 7(a) loans
        print("\n### Loading SBA 7(a) Loans...")
        df_7a_recent = self._download_csv(self.urls['7a_recent'])
        df_7a_2010 = self._download_csv(self.urls['7a_2010_2019'])
        df_7a = pd.concat([df_7a_recent, df_7a_2010], ignore_index=True)
        
        # Process and load
        df_7a_processed = self._process_7a_data(df_7a)
        self._load_to_database(df_7a_processed, 'sba_7a_loans')
        
        print(f"✓ Loaded {len(df_7a_processed):,} SBA 7(a) loans")
        
        # Download and load 504 loans
        print("\n### Loading SBA 504 Loans...")
        df_504 = self._download_csv(self.urls['504_recent'])
        df_504_processed = self._process_504_data(df_504)
        self._load_to_database(df_504_processed, 'sba_504_loans')
        
        print(f"✓ Loaded {len(df_504_processed):,} SBA 504 loans")
        
        # Create indexes for fast lookup
        self._create_indexes()
        
        print(f"\n{'='*60}")
        print("SBA DATA LOAD COMPLETE")
        print(f"{'='*60}")
    
    def _download_csv(self, url):
        """Download CSV from URL"""
        print(f"[DOWNLOAD] {url}")
        
        try:
            df = pd.read_csv(url, low_memory=False)
            print(f"[DOWNLOAD] ✓ Loaded {len(df):,} rows")
            return df
        except Exception as e:
            print(f"[DOWNLOAD] ✗ Error: {e}")
            return pd.DataFrame()
    
    def _process_7a_data(self, df):
        """
        Process 7(a) loan data
        Standardize columns for Chicago area
        """
        # Filter to Illinois (or specific state)
        df_il = df[df['BorrowerState'] == 'IL'].copy()
        
        # Select and rename columns
        df_processed = df_il[[
            'BorrowerName',
            'BorrowerStreet',
            'BorrowerCity',
            'BorrowerState',
            'BorrowerZip',
            'GrossApproval',
            'ApprovalDate',
            'NAICSCode',
            'JobsSupported',
            'BankName'
        ]].copy()
        
        # Rename for consistency
        df_processed.rename(columns={
            'GrossApproval': 'loan_amount',
            'ApprovalDate': 'approval_date',
            'NAICSCode': 'naics_code',
            'JobsSupported': 'jobs_supported',
            'BankName': 'lender_name'
        }, inplace=True)
        
        # Add loan type
        df_processed['loan_type'] = '7a'
        
        # Parse approval date
        df_processed['approval_year'] = pd.to_datetime(
            df_processed['approval_date'], 
            errors='coerce'
        ).dt.year
        
        return df_processed
    
    def _process_504_data(self, df):
        """
        Process 504 loan data
        CRITICAL: Has project address (property location!)
        """
        # Filter to Illinois
        df_il = df[df['BorrowerState'] == 'IL'].copy()
        
        # Select columns
        df_processed = df_il[[
            'BorrowerName',
            'BorrowerStreet',
            'BorrowerCity',
            'BorrowerState',
            'BorrowerZip',
            'ProjectStreet',      # ← Property address!
            'ProjectCity',
            'ProjectState',
            'ProjectZip',
            'GrossApproval',
            'ProjectCost',
            'ApprovalDate',
            'JobsSupported',
            'CDC_Name'
        ]].copy()
        
        # Rename
        df_processed.rename(columns={
            'GrossApproval': 'loan_amount',
            'ProjectCost': 'project_cost',
            'ApprovalDate': 'approval_date',
            'JobsSupported': 'jobs_supported',
            'CDC_Name': 'lender_name'
        }, inplace=True)
        
        # Add loan type
        df_processed['loan_type'] = '504'
        
        # Parse approval date
        df_processed['approval_year'] = pd.to_datetime(
            df_processed['approval_date'],
            errors='coerce'
        ).dt.year
        
        return df_processed
    
    def _load_to_database(self, df, table_name):
        """Load dataframe to SQLite database"""
        conn = sqlite3.connect(self.db_path)
        
        # Replace existing table
        df.to_sql(table_name, conn, if_exists='replace', index=False)
        
        conn.close()
    
    def _create_indexes(self):
        """Create indexes for fast lookup"""
        conn = sqlite3.connect(self.db_path)
        cursor = conn.cursor()
        
        # Indexes for 7(a) loans
        cursor.execute("""
            CREATE INDEX IF NOT EXISTS idx_7a_zip 
            ON sba_7a_loans(BorrowerZip)
        """)
        
        cursor.execute("""
            CREATE INDEX IF NOT EXISTS idx_7a_city 
            ON sba_7a_loans(BorrowerCity)
        """)
        
        cursor.execute("""
            CREATE INDEX IF NOT EXISTS idx_7a_year 
            ON sba_7a_loans(approval_year)
        """)
        
        # Indexes for 504 loans
        cursor.execute("""
            CREATE INDEX IF NOT EXISTS idx_504_project_zip 
            ON sba_504_loans(ProjectZip)
        """)
        
        cursor.execute("""
            CREATE INDEX IF NOT EXISTS idx_504_project_city 
            ON sba_504_loans(ProjectCity)
        """)
        
        cursor.execute("""
            CREATE INDEX IF NOT EXISTS idx_504_year 
            ON sba_504_loans(approval_year)
        """)
        
        conn.commit()
        conn.close()
        
        print("[INDEX] ✓ Created database indexes")


# Run this quarterly to update data
if __name__ == '__main__':
    loader = SBADataLoader()
    loader.download_and_load_all()
```

## FILE 2: `sba_loan_finder.py`

**Find SBA loans near a property (backend API)**

```python
"""
Find SBA loans near a property
Similar to HMDA loan finder
"""

import sqlite3
from datetime import datetime


class SBALoanFinder:
    """
    Find SBA loans near a property
    """
    
    def __init__(self, db_path='sba_loans.db'):
        self.db_path = db_path
    
    def get_loans_near_property(
        self,
        property_zip,
        property_city='Chicago',
        years_back=5,
        radius_zips=None
    ):
        """
        Get SBA loans near a property
        
        Args:
            property_zip: Property ZIP code
            property_city: Property city
            years_back: How many years of loan history
            radius_zips: List of nearby ZIP codes (optional)
            
        Returns:
            dict: {
                '7a_loans': [...],
                '504_loans': [...],
                'summary': {...}
            }
        """
        print(f"[SBA] Finding loans near {property_city}, {property_zip}")
        
        # Calculate year cutoff
        current_year = datetime.now().year
        min_year = current_year - years_back
        
        # Get 7(a) loans
        loans_7a = self._get_7a_loans(
            property_zip,
            property_city,
            min_year,
            radius_zips
        )
        
        # Get 504 loans (commercial real estate)
        loans_504 = self._get_504_loans(
            property_zip,
            property_city,
            min_year,
            radius_zips
        )
        
        # Calculate summary statistics
        summary = self._calculate_summary(loans_7a, loans_504)
        
        return {
            '7a_loans': loans_7a,
            '504_loans': loans_504,
            'summary': summary
        }
    
    def _get_7a_loans(self, zip_code, city, min_year, radius_zips):
        """Get 7(a) loans in area"""
        conn = sqlite3.connect(self.db_path)
        conn.row_factory = sqlite3.Row
        cursor = conn.cursor()
        
        # Build ZIP list
        zip_list = [zip_code]
        if radius_zips:
            zip_list.extend(radius_zips)
        
        zip_placeholders = ','.join(['?' for _ in zip_list])
        
        query = f"""
            SELECT 
                BorrowerName,
                BorrowerStreet,
                BorrowerCity,
                BorrowerZip,
                loan_amount,
                approval_date,
                approval_year,
                naics_code,
                jobs_supported,
                lender_name
            FROM sba_7a_loans
            WHERE (BorrowerZip IN ({zip_placeholders}) OR BorrowerCity = ?)
            AND approval_year >= ?
            ORDER BY approval_year DESC, loan_amount DESC
            LIMIT 100
        """
        
        params = zip_list + [city, min_year]
        cursor.execute(query, params)
        
        loans = [dict(row) for row in cursor.fetchall()]
        conn.close()
        
        print(f"[SBA] Found {len(loans)} 7(a) loans")
        return loans
    
    def _get_504_loans(self, zip_code, city, min_year, radius_zips):
        """
        Get 504 loans (commercial real estate)
        Uses PROJECT address (property location)
        """
        conn = sqlite3.connect(self.db_path)
        conn.row_factory = sqlite3.Row
        cursor = conn.cursor()
        
        # Build ZIP list
        zip_list = [zip_code]
        if radius_zips:
            zip_list.extend(radius_zips)
        
        zip_placeholders = ','.join(['?' for _ in zip_list])
        
        query = f"""
            SELECT 
                BorrowerName,
                ProjectStreet,
                ProjectCity,
                ProjectZip,
                loan_amount,
                project_cost,
                approval_date,
                approval_year,
                jobs_supported,
                lender_name
            FROM sba_504_loans
            WHERE (ProjectZip IN ({zip_placeholders}) OR ProjectCity = ?)
            AND approval_year >= ?
            ORDER BY approval_year DESC, loan_amount DESC
            LIMIT 100
        """
        
        params = zip_list + [city, min_year]
        cursor.execute(query, params)
        
        loans = [dict(row) for row in cursor.fetchall()]
        conn.close()
        
        print(f"[SBA] Found {len(loans)} 504 loans")
        return loans
    
    def _calculate_summary(self, loans_7a, loans_504):
        """Calculate summary statistics"""
        return {
            'total_7a_loans': len(loans_7a),
            'total_7a_amount': sum(l.get('loan_amount', 0) for l in loans_7a),
            'total_504_loans': len(loans_504),
            'total_504_amount': sum(l.get('loan_amount', 0) for l in loans_504),
            'total_loans': len(loans_7a) + len(loans_504),
            'total_amount': (
                sum(l.get('loan_amount', 0) for l in loans_7a) +
                sum(l.get('loan_amount', 0) for l in loans_504)
            )
        }


# Convenience function for integration
def get_sba_loans_for_property(property_data, years_back=5):
    """
    Get SBA loans near a property
    
    Args:
        property_data: Dict with 'zip' and 'city'
        years_back: Years of history
        
    Returns:
        dict: SBA loan data
    """
    finder = SBALoanFinder()
    
    return finder.get_loans_near_property(
        property_zip=property_data['zip'],
        property_city=property_data.get('city', 'Chicago'),
        years_back=years_back
    )
```

## TL;DR - REPLIT INSTRUCTIONS

**1. Create** `sba_data_loader.py`:
- Downloads SBA 7(a) and 504 loan CSVs
- Processes and loads into SQLite database
- Run once, then quarterly for updates

**2. Create** `sba_loan_finder.py`:
- Queries database for loans near property
- Returns 7(a) and 504 loans in area
- Backend API like your HMDA finder

**3. Integrate** into property reports:
```python
sba_data = get_sba_loans_for_property(property_data)
report['commercial_loans'] = sba_data
```

- **Format:** CSV downloads
- **Cost:** FREE
