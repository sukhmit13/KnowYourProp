## STANDARD RULES (enforce on every takeaway in the report)
1. **The jump chip (`.take-chip`) is a ROW SIBLING pinned far-right, vertically centered** (`flex:none; align-self:center; margin-left:auto`). It is NEVER placed inside the `.body` text — it must not read like punctuation trailing the sentence. A bullet with no destination simply omits the chip.
2. **One type scale, everywhere:** label `--take-label` (11px), headline `--take-title` (21px serif), body `--take-body` (13px). Do NOT resize these per section — that's the drift that produced a 24px headline in one section and 21px in another.
3. **Label word is always "Takeaway"** (mono uppercase) with the lightbulb icon. The section-specific synthesis lives in the serif headline, not the label. (Retire the old per-section labels like "Snapshot" / "What the record shows".)
4. **Dot color = favorability, and it's the ONLY place color varies:** `.good` green (genuinely positive), `.caution` marigold (a real watch-out), `.insight` indigo (derived/neutral read), default grey (plain context). Never red on a takeaway dot unless the section genuinely warrants it. Race/politics/demographics stay grey (see People Profile rules).
5. **Rating pill** (`.take-rating`) is OPTIONAL and right-aligned in the label row — use only when the section has a computed overall tier (Transit access, FAR verdict). Most sections omit it.
6. **Subtle row dividers** (`.take-row + .take-row`) separate bullets so each far-right chip clearly pairs with its row.
7. **Retrofit:** replace the takeaway markup in DOB, Sale History, Property Tax, Parcel, Liens, Schools, People Profile, Transit, Construction, New Business Licenses, FAR, etc. with THIS component. After retrofit, every takeaway is pixel-identical in chrome; only the words and dot colors differ.

## Section structure (verbatim reference = delivered `report-entculture.html`)
1. **Header:** square + "Entertainment & Culture" + count chip (`{N} Michelin · {N} James Beard · {N} murals`).
2. **Takeaway (Part B component)** — 3 bullets:
   - `.good` → dining standout ({N} Michelin within 1 mi, {N} Bib Gourmand, the James Beard winner). Chip → `#michelin`, label "Restaurants".
   - `.insight` → culture (murals count, landmarks, nearest gallery distance). Chip → `#murals`, label "Culture".
   - `.insight` → what it means for the property (desirability + foot-traffic, two-sided with the evening-activity/parking trade-off). No chip.
3. **Subsections**, each `.ssh` (outline icon) + `.rad` radius + `.chip` count, then `.row` list:
   - `#michelin` Michelin Guide Restaurants (utensils icon): name + `.aw` badge(s) + `meta` (cuisine · price · neighborhood) + `addr` + `.dist`. Truncate to ~6 with "Show all {N}".
   - James Beard Award Winners (trophy icon): the winner(s) with `.aw.jb` "{Award} · {Year}".
   - `#murals` Registered Murals (palette icon): name + `.yr` + "by {Artist} · {medium}" + `addr`.
   - `#landmarks` Architectural Landmarks (columns icon): name + `.yr` "Built {year}" + "Architect: {name} · Designated {year}" + `addr`.
   - Art Galleries (image icon): name + license tag + licensed date + `addr`.

## LOGIC
1. **Award badge from the Michelin distinction:** Bib Gourmand → `.aw.bib`; Selected → `.aw.sel`; a starred restaurant → a `★`×N badge (`.aw.bib` style); plain Michelin-listed → `.aw.mich`. A James Beard winner also gets a `.aw.jb` "James Beard" tag in its Michelin row.
2. **Cross-listing is intentional, not a dup:** a restaurant that is BOTH Michelin and a James Beard winner (e.g. Lula Cafe) appears in the Michelin list AND the James Beard subsection — different award bodies. De-dupe within a single list, not across the two subsections.
3. **Sort:** restaurants by distance ascending (a "what's near me" amenity list). If you'd rather lead with prestige, sort by tier (Bib Gourmand → Selected) then distance — pick ONE and keep it consistent.
4. **Radius per subsection is data-driven** (Michelin/JB/landmarks/galleries = 1 mi; murals = 0.5 mi) — show the actual radius in `.rad`, don't hardcode.
5. **Count chips** reflect real counts within each radius; "Show all" reveals the full list beyond the initial ~6.

## CRITICAL DETAILS
1. **Takeaway is the Part-B standard component** — same label(11px)/headline(21px serif)/body(13px), right-aligned centered chips. Not a bespoke E&C takeaway.
2. **Award badges are prestige-dark, never Michelin red** (red = status/bad in this report).
3. **One section takeaway on top; subsections are clean data with a summary chip**, no per-subsection takeaways.
4. **Dining bullet is `.good` (green)** — a genuine amenity positive — but the "what it means" bullet stays two-sided (foot-traffic upside + evening/parking trade-off), not pure hype.
5. **Cross-listed restaurant** (Michelin + James Beard) shows in both subsections by design; de-dupe only within a list.
6. **Subsection icons are 17px outline** (utensils / trophy / palette / columns / image); section header is the filled indigo square.
7. Serif (`--disp`) only on the takeaway headline. Everything else Inter; labels/dates/distances/sources Mono.
