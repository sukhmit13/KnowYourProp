6. Caching hook (small, but required)

The Takeaway text is produced by a Claude API call (Part B). Do not call the API on page render. Generate it once when a property's analysis runs, store the returned JSON on the report record (e.g. report.crime.takeaway), and the front-end just renders that stored object. Regenerate only when the crime data for the property is refreshed. This makes takeaways free on every view.

Consistency
Red = violent crime only (and genuinely-bad states). Green = good. Neutral grey = middling. Never blanket-red a section.
Every accent is indigo / green / red / neutral per the tokens; nothing black; no beige fills.
