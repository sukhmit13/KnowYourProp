# Replit Prompt — Standard Section Structure (apply to EVERY section with a takeaway)

A single canonical scaffold for the top of every section. Today sections diverge: some wrap the takeaway in an extra card, some repeat the title, some add a grey divider, some don't. Standardize all of them to this. Implement **verbatim**; check CRITICAL DETAILS.

## The canonical structure — exactly three parts, in this order
```
1. Section header      — filled indigo square + mono uppercase title, optional right-aligned scope chip
2. Takeaway box        — the shared Standard Takeaway component, DIRECTLY below the header
3. Section data        — the section's charts/tables/cards
```
Nothing else between 1 and 2. No wrapper. No repeated title. No divider line.

## 🔴 The four rules that fix the current drift
1. **The takeaway box is the ONLY framed element at the top.** It already has its own tint + border — do **not** put it inside a second bordered card. (New Business Licenses currently double-frames it; remove the outer card.)
2. **One title per section = the section header.** Never repeat the section name on a card header inside the section. If a section currently shows its title twice (header + card), delete the card's copy.
3. **No divider between header and takeaway.** Spacing only (`.secthead` margin-bottom). Remove any `<hr>` / grey rule sitting between the section header and the takeaway.
4. **Scope/meta chip goes on the section-header row**, right-aligned — not on a duplicate-title card. (e.g. `33 businesses · 1 mi · 12 mo`.) It's optional per section; omit when there's nothing to scope.

## Spacing (standardize the vertical rhythm)
- `.secthead` → takeaway: **16px** (`.secthead margin-bottom`). No rule/line.
- Takeaway → first data element: **~18–22px** margin on the data block (section's choice, consistent within the report).
- Between sections: the page's existing section gap (unchanged).
- No subtitle line under the header by default (they were removed as redundant). If a section genuinely needs one, it's a single muted line between header and takeaway with its own small margin — still no card, no divider.

- [ ] Move any scope/count chip to the `.secthead` row (`.scope`, right-aligned).

## CRITICAL DETAILS
1. **One frame** (the `.take` box), **one title** (the `.secthead`), **no divider**, **scope chip on the header row** — these four together are the fix.
2. **Shared Standard Takeaway component** everywhere — identical label/headline/body sizes and far-right centered chips. Not a per-section variant.
3. **Serif (`--disp`) ONLY** on `.take-title` (and the section's own big data numbers). Header + label + chip are Mono.
4. **This is layout, not content** — pure code, zero LLM tokens. The takeaway text still comes from the generator; only the frame around it is standardized here.
