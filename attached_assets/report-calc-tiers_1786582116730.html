Same $96,950 both sides. Simple isn't a lighter calculation — it's the full expense model with the lines collapsed behind defaults. Flip to Advanced to edit any line. Simple can never revert to "rent − taxes − insurance" (the fake-15%-cap bug).
Funnel defaults, section overrides. The intended-use funnel sets the mode (Investor / Owner-occupant / Tenant); whether they filled the deal inputs sets the tier (Advanced if they did, Simple if they skipped). Both are one click to change in the header — so a wrong guess or a skipped funnel is never a dead end.
Don't conflate the knobs. Simple↔Advanced is a view of one mode; Investor/Owner-occupant/Tenant is a different calculation. Two axes, not one four-way switch.
