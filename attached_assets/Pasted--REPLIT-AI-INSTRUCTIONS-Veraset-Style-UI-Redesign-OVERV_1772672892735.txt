# REPLIT AI INSTRUCTIONS: Veraset-Style UI Redesign

## OVERVIEW
Transform the Chicago property intelligence platform to match Veraset.com's sophisticated, minimalist aesthetic while keeping ALL existing data sections and functionality intact.

---

## VERASET DESIGN SYSTEM ANALYSIS

### COLORS
```
Black:        #000000 (primary background for hero sections)
White:        #ffffff (text on black, card backgrounds)
Beige:        #e5ddd5 (secondary background, sidebar, card backgrounds)
Off-white:    #f5f5f5 (subtle backgrounds)
Text dark:    #1a1a1a (body text on light backgrounds)
Neon yellow:  #c4ff00 (primary CTA buttons)
Light blue:   #7dd3fc (accents, diagrams)
Orange:       #ff6b35 (highlights, secondary accents)
```

### TYPOGRAPHY
- **Headlines**: Large, bold, monospace feel (48px desktop, 32px mobile)
- **Body**: Clean sans-serif, 18px, line-height 1.8
- **Spacing**: Very generous (1.8-2.0 line height)
- **Style**: Some section labels in ALL CAPS

### LAYOUT PRINCIPLES
- **Massive white space** (80-120px section padding)
- **Two-column layouts** (50/50 text and image/diagram splits)
- **Sharp edges** (NO rounded corners - border-radius: 0)
- **Flat design** (NO shadows, NO gradients)
- **High contrast** (black text on white, white text on black)
- **Minimalist** (every element has purpose)

### COMPONENTS
- **Buttons**: Neon yellow with black text, or black with white text, sharp corners
- **Cards**: Beige or white backgrounds, NO shadows, sharp corners
- **Icon boxes**: 80x80px beige squares with simple black icons
- **Tables**: Clean, minimal borders, beige headers
- **Sidebar**: Beige background, simple text links
- **NO visual effects**: No drop shadows, no gradients, no rounded corners
