STEP 2: CREATE CACHING UTILITY
═══════════════════════════════════════════════════════════════════════════

Create /server/utils/cache.js:

This utility handles all caching operations. Cache files are stored in 
/server/data/cache/{category}/{key}.json

Key functions:
- checkCache(key): Returns cached data if valid, null if expired/missing
- saveCache(key, data, daysValid): Saves data with expiration
- isExpired(cached, daysValid): Checks if cache is still valid
- hashAddress(address): Creates consistent hash from address string

Cache durations:
- Property tax: 30 days (changes slowly)
- Foreclosure: 14 days (legal processes are slow)
- Liens: 7 days (can be filed anytime)
- Water bill: 30 days (monthly billing)

Example cache file structure:
{
  "data": { /* actual data */ },
  "cached": "2026-01-28T10:00:00Z",
  "expiresIn": 30,
  "expiresAt": "2026-02-27T10:00:00Z"
}

─────────────────────────────────────────────────────────────────────────────
SERVICE 1: getPropertyTaxStatus(pin)
─────────────────────────────────────────────────────────────────────────────

URL: https://www.cookcountytreasurer.com/search/
Input: PIN (Property Index Number)
Cache: 30 days
Method: Puppeteer (site uses JavaScript)

Steps:
1. Check cache for `property_tax/${pin}.json`
2. If cached and valid, return cached data
3. Launch headless browser
4. Navigate to treasurer site
5. Enter PIN in search field
6. Click search button
7. Wait for results to load
8. Extract data:
   - Current year 1st installment status (PAID/UNPAID)
   - Current year 2nd installment status (PAID/UNPAID)
   - Prior year status (PAID/UNPAID)
   - Total amount owed (dollar amount)
   - Tax sale status (Yes/No/Pending)
9. Save to cache
10. Return data

Data structure to return:
{
  pin: string,
  currentYear1st: { status: 'PAID'|'UNPAID', amount: number },
  currentYear2nd: { status: 'PAID'|'UNPAID', amount: number },
  priorYear: { status: 'PAID'|'UNPAID', amount: number },
  totalOwed: number,
  taxSaleStatus: 'None'|'Pending'|'Sold',
  lastChecked: timestamp
}

Error handling:
If scraping fails, return:
{
  error: true,
  message: 'Unable to verify property tax status',
  manualCheckUrl: 'https://www.cookcountytreasurer.com/search/',
  lastChecked: timestamp
}

SERVICE 2: getForeclosureStatus(address)
─────────────────────────────────────────────────────────────────────────────

URL: https://www.cookcountyclerkofcourt.org/
Input: Street address
Cache: 14 days
Method: Puppeteer (court site uses JavaScript)

Steps:
1. Check cache for `foreclosure/${hashAddress(address)}.json`

3. Launch headless browser
4. Navigate to circuit court case search
5. Select "Address Search" option
6. Enter address
7. Select case type "CH" (Chancery - includes foreclosures)
8. Set date range to last 5 years
9. Click search
10. Wait for results
11. Extract all foreclosure cases:
    - Case number
    - Filed date
    - Status (PENDING/ACTIVE/CLOSED/DISMISSED)
    - Plaintiff (usually the lender)
12. Categorize cases:
    - activeCases: status includes PENDING or ACTIVE
    - closedCases: status includes CLOSED or DISMISSED
13. Save to cache
14. Return data

Data structure to return:
{
  hasForeclosure: boolean,
  activeCases: [
    { caseNumber, filedDate, status, plaintiff }
  ],
  closedCases: [
    { caseNumber, filedDate, status, plaintiff }
  ],
  totalCases: number,
  lastChecked: timestamp
}

Error handling:
If scraping fails or no results found, return:
{
  hasForeclosure: false,
  activeCases: [],
  closedCases: [],
  totalCases: 0,
  note: 'Unable to verify or no cases found',
  manualCheckUrl: 'https://www.cookcountyclerkofcourt.org/',
  lastChecked: timestamp
}

─────────────────────────────────────────────────────────────────────────────
SERVICE 3: getRecentLiens(pin)
─────────────────────────────────────────────────────────────────────────────

URL: https://www.cookcountyil.gov/service/records-search
Input: PIN (Property Index Number)
Cache: 7 days
Method: Puppeteer (recorder site uses JavaScript)

Steps:
1. Check cache for `liens/${pin}.json`
2. If cached and valid, return cached data
3. Launch headless browser
4. Navigate to recorder of deeds search
5. Select "PIN Search"
6. Enter PIN
7. Set date range: 10 years ago to today
8. Click search
9. Wait for document results
10. Extract all documents and categorize:
    - MORTGAGES: doc type includes "MORTGAGE" or "DEED OF TRUST"
    - LIENS: doc type includes "LIEN" (but not "RELEASE")
    - RELEASES: doc type includes "RELEASE"
    - DEEDS: doc type includes "DEED" (but not "TRUST" or "MORTGAGE")
11. For each document, extract:
    - Document type
    - Recorded date
    - Document number
    - Grantor (who is giving)
    - Grantee (who is receiving)
    - Amount (if available)
12. Determine active liens:
    - A lien is active if no corresponding release exists
    - Match by document number or date proximity
13. Classify each active lien:
    - JUDGMENT LIEN: severity HIGH, must be paid at closing
    - MECHANIC'S LIEN: severity HIGH, contractor dispute
    - IRS/TAX LIEN: severity CRITICAL, not financeable
    - HOA LIEN: severity MEDIUM, must be paid at closing
14. Analyze ownership transfers:
    - Count total transfers in 10 years
    - Check for quick flips (multiple sales in <24 months)
    - Check for foreclosure indicators (bank ownership, trustee deeds)
    - Check for quit claim deeds (less protection)
15. Save to cache
16. Return data

Data structure to return:
{
  mortgages: [
    { docType, recordedDate, amount, lender }
  ],
  liens: [
    { docType, recordedDate, amount, creditor, severity, category }
  ],
  activeLiens: [
    { docType, recordedDate, amount, creditor, severity, impact }
  ],
  releases: [
    { docType, recordedDate }
  ],
  ownership: {
    transfers: number,
    currentOwner: string,
    currentOwnerSince: date,
    previousOwners: [ { owner, dateSold } ],
    redFlags: [
      { flag: string, detail: string, impact: string }
    ]
  },
  lastChecked: timestamp
}

Lien classification logic:
- If docType includes 'JUDGMENT': category='judgment', severity='high'
- If docType includes 'MECHANIC': category='mechanic', severity='high'
- If docType includes 'IRS' or 'TAX': category='tax', severity='critical'
- If docType includes 'HOA' or 'ASSOCIATION': category='hoa', severity='medium'
- Otherwise: category='other', severity='medium'

Ownership red flags to detect:
- 3+ transfers in <24 months → "Frequent transfers - possible flip"
- Grantee includes 'BANK' or 'REO' → "Bank-owned (REO) - former foreclosure"
- DocType includes 'TRUSTEE' → "Trustee's deed - foreclosure transfer"
- DocType includes 'QUIT CLAIM' → "Quit claim deed - less protection"

Error handling:
If scraping fails, return:
{
  error: true,
  message: 'Unable to verify lien status',
  manualCheckUrl: 'https://www.cookcountyil.gov/service/records-search',
  lastChecked: timestamp
}

Create /server/routes/preTitleCheck.js

This is the main API endpoint that orchestrates all checks and returns results.

ENDPOINT: POST /api/pre-title-check

REQUEST BODY:
{
  pin: "14-08-203-018-0000",
  address: "1542 N Western Ave, Chicago, IL",
  propertyClass: "211" (from Cook County Assessor data you already have)
}

PROCESS:
1. Validate inputs (PIN and address required)
2. Run all services in parallel using Promise.allSettled():
   - getPropertyTaxStatus(pin)
   - getForeclosureStatus(address)
   - getRecentLiens(pin)
   - getWaterBillStatus(address)
   - Get building violations (use your existing code)
3. Wait for all to complete (even if some fail)
4. Calculate overall verdict based on results
5. Return comprehensive response

VERDICT CALCULATION LOGIC:

Start with score = 100, then subtract points for issues:

Property Tax:
- Total owed > $5,000: -50 points, CRITICAL, "NOT FINANCEABLE until paid"
- Total owed $1-$5,000: -20 points, WARNING, "Must be paid at closing"
- Tax sale pending: -50 points, CRITICAL, "NOT FINANCEABLE"

Foreclosure:
- Active case exists: -50 points, CRITICAL, "NOT FINANCEABLE until resolved"
- Recent closed case (within 2 years): -20 points, WARNING, "Verify title clear"

Liens:
- IRS/Tax lien: -50 points, CRITICAL, "NOT FINANCEABLE until cleared"
- Judgment lien: -30 points, HIGH, "Must be paid at closing"
- Mechanic's lien: -30 points, HIGH, "Must be resolved"
- HOA lien: -20 points, MEDIUM, "Must be paid at closing"

Building Violations (use your existing code):
- Open structural violation: -50 points, CRITICAL, "NOT FINANCEABLE"
- Open fire safety violation: -50 points, CRITICAL, "NOT FINANCEABLE"
- Open minor violation: -10 points, INFO, "Verify with DOB"

Water Bill:
- Balance > $1,000: -10 points, INFO, "Add to closing costs"

Ownership Red Flags:
- Quick flip (<6 months): -15 points, WARNING, "Inspect carefully"
- Recent foreclosure: -10 points, INFO, "Review title carefully"

FINAL VERDICT:
- Score >= 80: ✅ LIKELY FINANCEABLE (green)
- Score 50-79: ⚠️ FINANCING MAY BE DIFFICULT (yellow)
- Score < 50: 🚩 NOT FINANCEABLE (red)
