## LOGIC (derived — compute in the backend)
1. **Effective status** for each license, from `(raw_status, start_date, end_date, today)`:
   - `cancelled` → status class `cancelled`, label "Cancelled" (a cancellation is explicit; keep it regardless of dates).
   - else if `end_date` is in the **future** (or no end date) → `active`, "Active".
   - else (`end_date` in the **past**) → `expired`, "Expired" — **even if `raw_status` says "Active."**
2. **Discrepancy flag.** When `raw_status == "Active"` (or "AAI"/"issued"-type) BUT `end_date` is in the past, render the inline `.flag` on that row: `Record says "{raw_status}" — term ended {year}`. Also show the footer `.caveat` when ≥1 row is flagged (omit the caveat entirely if none).
3. **Header count.** `{ACTIVE_COUNT}` = number of licenses whose **effective** status is `active` — NOT the raw status field. (For this property that's 1, not 2.) `{TOTAL}` = all licenses.
4. **Snapshot** (hardcoded/computed, not the Claude engine): headline summarizes the kinds of businesses + the since-year; bullet 1 names the single active license and its end year; bullet 2 summarizes the lapsed ones. If `ACTIVE_COUNT == 0`, change bullet 1 to "No active licenses today" and adjust the headline. If there's exactly one license total, collapse to a single line.
5. Order rows **newest first** by start date (or end date). "Limited Business License" is the license type from the data — display verbatim.

## CRITICAL DETAILS (check ALL)
1. **Status is DERIVED from dates, not copied from the raw status field.** The G&R-style case (raw "Active", ended 2009) must render **Expired** with the amber flag — this is the whole point of the section.
2. **Status pill colors:** Active = green dot + green text on `--goodSoft`. Expired = grey dot + `--ink2` on paper w/ border. Cancelled = light-grey dot + `--muted` on paper w/ border. **None are red** — an expired/cancelled license isn't "bad," just inactive (professionals-neutral rule: color the state, not the business).
3. **License-type tag** ("Limited Business License") is an indigo-soft pill (`.ltype`), separate from the status pill.
4. **The inline `.flag`** (amber alert-triangle + text) appears only on discrepant rows; the footer `.caveat` appears only when ≥1 discrepancy exists. No discrepancies → neither shows.
5. **Header count uses EFFECTIVE active count** (the green `<b>`), so header and rows agree.
6. **Header uses the filled indigo SQUARE** (top-level section).
7. **Snapshot is the indigo takeaway box**, serif headline, "SNAPSHOT" mono label; bullet-1 dot is green (the active business), bullet-2 dot neutral grey.
8. **Rows** have a top border each and a bottom border on the last (`.lrow:last-of-type`); name left / date-range right (mono, muted); tags row below.
9. Serif (`--disp`) only on the snapshot headline. Everything else Inter; labels JetBrains Mono.
