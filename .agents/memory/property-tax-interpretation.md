---
name: Property tax interpretation
description: Guardrails for presenting Cook County bills, assessment levels, and property-tax ratios.
---

Treat only a bill with both installments as a complete tax year. A first-installment-only year has no meaningful year-over-year full-bill change. State the 55% statutory advance relationship only when the actual installment divided by the prior complete bill confirms it.

**Why:** A screenshot-based tax design treated a first installment as the headline and mistook a Chicago zoning code for evidence of a residential assessment level. The example parcel's actual assessor class was commercial, so assuming 10% would overstate its assessor-implied market value by 2.5×.

**How to apply:** Use the latest complete Treasurer bill for annual totals and clearly distinguish part-billed years. Use an actual Assessor class to infer the assessment level; if the class has a special/incentive or unknown rate, omit the implied value and bill-to-value ratio. Label differing tax years in the operands and never imply that this ratio is the buyer's future sale-price rate. Do not infer occupancy or exemption eligibility from zoning alone.
