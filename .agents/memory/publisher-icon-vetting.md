---
name: Publisher icon vetting
description: Avoid wrong-brand favicons and verify official app artwork when sourcing compact publisher logos.
---

Verify the pictured brand rather than accepting a favicon solely because it came
from the requested domain. A redirect can return a different publisher's logo.
Official app artwork is a useful higher-resolution source, but verify both the
app name and seller before using it.

**Why:** Chicago Magazine's site and favicon lookup returned a Tribune icon.
Time Out app searches included unrelated screen-time utilities. The Tribune's
site icon was only 16px, while its verified publisher app offered a clear
high-resolution monogram.

**How to apply:** Inspect artwork at the actual news-tile size, reject mismatched
or unreadable results, and preserve a verified existing mark when no appropriate
replacement is available. Do not invent a monogram to fill the gap.
